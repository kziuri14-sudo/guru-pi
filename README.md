# guru-pi

Raspberry Pi programa (GURU G⚽AL signalai, grupių auditas, būsenos puslapis).
Raspberry kas 10 min. tikrina šiuos failus (`main` šaka) ir pats atsinaujina:
`pi_guru.py`, `pi_audit.py`, `results.py`, `props.py`, `dash.html`.
Slaptažodžių ir raktų čia nėra – jie tik Raspberry `pi_config.json`.
